# Security policy

TamarackDB is pre-1.0. The latest release is the only version that
receives security fixes.

## Reporting a vulnerability

Report vulnerabilities through GitHub's private vulnerability
reporting: open the "Security" tab on this repository, then "Report a
vulnerability". This creates a private advisory that only the
maintainer can see, so details stay confidential until a fix is ready.

Do not open a public issue for a security vulnerability.

If a report is confirmed, a fix is released as soon as practical, and
the advisory credits you unless you ask otherwise.
